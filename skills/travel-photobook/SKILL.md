# 旅行照片书

用户给照片目录后，完成制作并返回PDF、离线HTML和跨页总览图片三个成品。默认使用宿主当前的视觉能力，不绑定模型厂商，不要求额外API密钥。

需要授权照片目录、程序执行和真实图片审阅能力；首次准备需联网下载固定版本的运行组件和图像编码模型。

1. 读取[执行与审阅协议](references/workflow.md)。安装或更换宿主时读取[平台接入](references/platforms.md)。
2. 定位当前技能目录，用scripts/photobook.sh或scripts/photobook.ps1自动准备运行组件并执行doctor。没有真实看图或本地执行能力时说明具体缺项，不能冒充兼容。
3. 使用用户提供的目录；无额外偏好就用默认值，建立或恢复同一job。持续advance，按任务实际看图、核实地点并提交结构化结果，不把待审任务交给用户完成。
4. 精选按事件覆盖、代表性、情绪与互补信息；本地向量只提供相似候选。分批聚类后完成全书事件复核，精选后逐张复看落选图再编排故事。地名须有证据。排版使用通用editorial_v1策略，保留简洁文案和compact-v1阅读器。
5. 真看最终页面，有问题返回对应环节修正，所有判断保留。禁止用合成测试答复、旧旅行答案或源JSON替代视觉检查。
6. 仅在全部检查通过后deliver。结果目录只有照片书.pdf、照片书.html和跨页总览.jpg，最后回复给出三个真实文件。跨页总览必须包含封面和全部内页，左右页顺序与照片书一致。原图不改动，中间记录留在内部job。

程序与模型自动下载若失败，按错误有限次恢复；不要悄悄跳过阶段或伪造完成。不同宿主可能显示工具过程或要求首次授权，按平台正常权限执行。
