# 旅行照片书

**把一趟旅行的照片，做成一本照片书。**

给它一个照片文件夹，它会帮你挑选照片、整理旅程、完成排版，生成可以打印的 PDF 和可以离线翻阅的网页。

## 怎么使用

在 AI 助手中选择照片文件夹，或告诉它文件夹的位置，然后发送：

> 用这个技能，把「我的照片文件夹」做成照片书：https://github.com/wayneLin0525/travel-photobook-skill

首次使用时，助手会自动安装技能并准备所需组件。安装之后，直接说：

> 把这个文件夹做成照片书。

不需要自己安装模型、整理照片或设置排版参数。有想法时，也可以顺便告诉它，例如“多保留家人的照片”。

## 你会得到什么

- **一本 PDF 照片书**：方便保存和打印。
- **一个翻页网页**：打开就能像翻书一样浏览，支持离线使用。

原始照片会保留，制作结果另存为新文件。再次制作时保存为新版本，保留之前的结果。

*目前提供 Mac M 系列芯片电脑的测试版，不同 AI 助手的使用情况仍在验证中。*

## 照片书是怎么做出来的

从一堆照片到一本照片书，会经过这些步骤：

**导入照片 → 初筛 → 去重 → 整理事件 → 精选 → 编排故事 → 排版 → 检查并生成**

| 环节 | 会做什么 |
|---|---|
| 导入照片 | 读取照片、拍摄时间和已有的位置信息，建立素材清单。 |
| 初筛 | 检查损坏、误拍和明显不可用的照片，同时保留有纪念价值的特殊瞬间。 |
| 去重 | 对比重复照片和相似连拍，留下更有代表性的画面。 |
| 整理事件 | 结合时间、地点和画面内容，把照片整理成不同的旅程片段。 |
| 精选 | 兼顾重要事件、人物、情绪和画面变化，选出适合入书的照片。 |
| 编排故事 | 按旅程安排先后顺序，检查重要片段是否遗漏，并重新查看落选照片。 |
| 排版 | 根据照片的重要程度、横竖比例和相互关系，安排大小、组合与留白，配上简短文字。 |
| 检查并生成 | 逐页检查照片、文字和排版，通过后生成 PDF 和离线翻页网页。 |

地点有依据才会写入；无法确认的地方会保留未知，不编造地名。

## 这个项目有什么优点

### 让照片讲清楚一趟旅程

选片时兼顾事件覆盖、人物和情绪，让出发、途中、重要经历与日常细节共同组成完整的旅行记录。

### 让每张照片各有作用

重要瞬间获得更大的展示空间，环境、食物和小细节负责补充氛围。照片组合有主次，也有变化。

### 让照片成为主角

采用简洁排版、适当留白和简短文字，减少复杂装饰，让注意力留在照片上。

### 一次制作，两种阅读方式

PDF 用于保存和打印，翻页网页用于日常浏览。网页不需要部署网站，打开文件就能看。

### 保留原图，也保留调整依据

筛选不会删除原始照片。哪些照片没有入选、为什么选择这些照片，都会保留内部记录，方便之后检查和调整。

## 常见问题

### 我需要提前整理照片吗？

准备一个旅行照片文件夹即可，不必提前去重、分组或挑选。

如果有特别重要的人物、地点或必须保留的照片，可以告诉助手；这些都不是必填项。

### 我需要自己安装 Python 或模型吗？

不需要。正常情况下，助手会自动准备运行组件和本地图片分析模型。

首次使用可能需要允许助手访问照片文件夹和执行程序，按所用工具的授权提示操作即可。

### 第一次使用需要下载多少东西？

当前测试版首次准备约需下载 **820 MB**，主要是制作程序、运行依赖和图片分析模型。

下载完成后会保留缓存，之后制作其他照片书通常不需要重复下载。首次准备时间取决于网络速度，项目还会继续优化安装体积。

### 需要额外购买大模型 API 吗？

项目不要求额外填写大模型 API Key，使用你当前 AI 助手已有的看图和执行能力。

AI 助手自身的订阅、额度或收费，按对应平台的规则计算。

### 照片会上传吗？

本地图片分析、排版和文件生成在电脑上执行，项目不会自动把照片书发布到公网。

助手看图时，照片是否发送到其云端服务，取决于你使用的 AI 工具及其设置。

### 结果保存在哪里？

助手会将成品保存到独立文件夹，并在完成后给出两个文件的位置。再次制作时使用新版本，避免覆盖已有结果。

也可以主动指定保存位置。

### 所有照片都能认出具体地点吗？

不能保证。系统会结合照片里的位置信息、可见招牌和其他可靠线索核实地点。证据不足时，不填写未经确认的城市或景点。

### PDF 可以直接交给印刷店吗？

可以用于保存和打印。制作实体照片书时，建议先向印刷店确认尺寸、出血和装订要求。

## 目前支持哪些设备和 AI 助手

| 项目 | 当前状态 |
|---|---|
| Mac M 系列芯片电脑 | 已提供测试版运行包 |
| Intel Mac、Windows | 尚未提供对应运行包 |
| 本机 Codex 制作流程 | 已完成真实旅行照片测试 |
| WorkBuddy、Claude、千问等助手 | 需要分别验证安装与完整制作体验 |

AI 助手需要能够安装技能、访问本地照片、执行程序并查看图片。

当前版本为公开测试版，欢迎反馈安装或制作过程中遇到的问题。请提供工具名称、电脑系统和报错信息，无需公开私人照片。
